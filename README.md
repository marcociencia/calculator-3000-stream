# 🧮 Calculator 3000 - The Stylish Arithmetic Machine

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://calculator-3000-marcociencia.streamlit.app)

## 🚀 Features

- ✅ **Stylish Typographic Layout** - Mimics a beautiful notebook aesthetic
- ➕ **Intelligent Operator Break** - When typing `+`, `-`, or `x`, the interface visually breaks to a secondary line
- 🔢 **Primary & Secondary Numbering** - Distinguishes between input phases
- 📊 **Instant Results** - Math appears beneath the line instantly
- 🧠 **Session State Logic** - Tracks inputs seamlessly without crashing

## 🛠️ Tech Stack

- **Python 3.8+**
- **Streamlit 1.28+**
- **Pandas** (Optional for analytics)
- **Session State** (No external database required)

## 🚀 Quick Start

```bash
git clone https://github.com/marcociencia/calculator-3000-streamlit.git
cd calculator-3000-streamlit
pip install -r requirements.txt
streamlit run app.py
